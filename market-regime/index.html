How the K-Means Model Works

This is a causal K-means regime detector with a fixed switching penalty (λ).

  1. Build four backward-looking features: log_return, momentum_20, volatility_20, drawdown
  2. Fit 3-means clustering using past data only — the current row is never in its own training set
  3. Label clusters: highest momentum center = Bull, lowest = Bear, middle = Neutral
  4. When classifying, add λ to any cluster that differs from the previous regime
  5. Higher λ = fewer switches = more stable (but slower to react to real changes)

Based on the jump model described in "How do quants detect a market regime change in real time?" — 2024 Princeton research using k-means with switching costs. Backtest showed S&P drawdown reduced from ~55% to ~27% with λ tuning.

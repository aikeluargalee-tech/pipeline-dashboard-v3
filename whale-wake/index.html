🐋 Whale Wake

Cross-venue BTC shock detector — research prototype

⚠️ Research software — not trading intelligence. No validated edge, no calibrated thresholds, no historical evidence of positive expectancy. Observation and paper signals only. No orders, no API keys, no exchange access.

🔴 Local analysis tool

Whale Wake is a Python application that watches Binance Futures, Binance Spot, and Coinbase Spot for cross-venue BTC impulses. Detects genuine multi-venue moves and flags futures-only traps.

No orders. No API keys. No exchange access.

📂 GitHub: whale-wake — clone and run locally. Not available as a live web page.

Quick Start

Clone and run locally:

git clone https://github.com/aikeluargalee-tech/whale-wake
cd whale-wake && ./START_WHALE_WAKE.sh

Then open http://127.0.0.1:8787 in your browser

Demo mode works offline. Live mode needs exchange connectivity.

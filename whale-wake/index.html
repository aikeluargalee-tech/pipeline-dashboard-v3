Whale Wake runs as a local server on port 8787. It watches live exchange feeds and scores every BTC shock in real time.

No orders. No API keys. No exchange access. Observation and paper signals only.

Quick Start

From the project directory:

cd ~/projects/whale-wake
./START_WHALE_WAKE.sh

Then open http://127.0.0.1:8787 or click the button above.

Demo mode works without internet. Live mode needs Binance + Coinbase connectivity.

What it detects

Whale Wake watches for sudden, unexplained BTC movement across three independent venues. When all three agree on direction with volume confirmation, it scores the move 0–10 and tracks it through a pullback → continuation cycle. If futures move sharply but spot venues disagree, it calls a trap veto — the most dangerous pattern for retail traders chasing candles.

It also tracks FOMC probability shifts (hike/hold/cut) via the FedWatch integration, detecting policy repricing events that may drive BTC moves.
